# Fonts

Drop the **Cute Planner** `.ttf` or `.otf` file in this folder (it is a paid
font, so it isn't in the repo). The app registers every font file in here at
launch and uses the first one whose name contains "cute" or "planner".

If the folder is empty the app falls back to SF Rounded, which looks close.

Lock-screen (shield) text can't use a custom font – Apple only lets us pick
the words and colours there.
